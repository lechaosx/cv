# Drahomír’s CV

A static bilingual CV for https://dlabaja.eu, edited in Pages CMS or `src/content/cv.yaml` and published with GitHub Pages.

```sh
nix develop
npm ci
npm run dev
```

With direnv, run `direnv allow` once to enter the Nix shell automatically.

Run `npm run check`, `npm test`, and `npm run test:e2e` before publishing. Browser checks use stable fixtures in `dist-e2e/`; `dist/` remains the production build. The Nix shell supplies Node 24 and matching Playwright browsers.

## Editing

Edit `src/content/cv.yaml` directly or open this repository in [Pages CMS](https://app.pagescms.org) on `master`. Fill both translations of each translated field, or omit both. About Me and timeline descriptions accept Markdown paragraphs, lists, emphasis, and links through the rich-text editor or its source view.

## Publishing and printing

Configure GitHub Pages to use **GitHub Actions** and [configure the custom domain and HTTPS](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site). Keep `astro.config.mjs` and `public/CNAME` aligned with the domain. Pushes to `master` publish after checks pass.

Pushes changing only `src/content/` or `public/uploads/` skip code and browser tests while still validating content, building the site and PDFs, and checking published output. Code changes, pull requests and manual runs use the full checks.

Each language offers a one-page A4 PDF download, generated from the current page on demand in `npm run dev` and regenerated by `npm run build` for publishing. If the fitted body text falls below 9pt, the build log and the GitHub Actions run summary show a warning; the development server logs it for each download. Both require Chromium; outside the Nix shell, install it with `npx playwright install --with-deps chromium`.
